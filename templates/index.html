📊 Google Sheets

To save results to Google Sheets, set up OAuth credentials:

  1. Go to Google Cloud Console → Credentials
  2. Create an OAuth 2.0 Client ID (type: Web application)
  3. Add Authorised redirect URI: http://localhost:5050/api/sheets/callback
  4. Enable the Google Sheets API and Google Drive API in your project
  5. Download the JSON and save it as client_secret.json in the app folder
  6. Restart the server, then click Connect below
